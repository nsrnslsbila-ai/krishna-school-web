# Content replacement checklist (after client approval)

- [ ] Institution: exact official name and branch identity
- [ ] Brand: approved logo, colors, typography and trademark permission
- [ ] School story: verified foundation year, institutional history, mission and vision
- [ ] Credentials: current school permits, NPSN and accreditation by **specific** academic level, proof/approval to publish
- [ ] Teaching approach: actual curriculum and Montessori implementation; verify teacher certification separately
- [ ] Programs: real ages, eligibility, grade structure, schedules, fees, term dates, and enrollment requirements
- [ ] Team: approved educator names, photos and credentials
- [ ] Location: accurate campus address, directions, opening hours and campus-specific contacts
- [ ] Media: real campus, classroom, teacher and student images with required permissions and child privacy safeguards
- [ ] Activities: approved class activities, real gallery stories and categories
- [ ] Events: real event dates, registration windows, capacities and event policies
- [ ] Lead handling: email/WhatsApp/CRM endpoint, staff assignment, spam protection, rate limiting, server-side validation
- [ ] Legal: privacy notice, data retention plan, consent, child data minimization, contact policy
- [ ] Languages: final Indonesian / English copy, proofread by institution
- [ ] Web: replace `noindex`, set canonical URLs, configure domain and analytics if approved
- [ ] Quality: keyboard and screen-reader testing, field validation, broken-link tests, responsive and performance QA
