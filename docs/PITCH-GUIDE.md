# PITCH GUIDE — Krishna Montessori Website Concept

## The 60-second pitch

"Kami ingin website Krishna bukan cuma brosur digital, tetapi pengalaman pertama orang tua mengenal sekolah. Mereka bisa melihat filosofi pendidikan, program pembelajaran, atmosfer kegiatan, dan menemukan jalur belajar yang relevan untuk anaknya — sampai akhirnya diarahkan ke school tour dan admissions. Desainnya sengaja hangat, bersih, playful, dan tetap kredibel."

## Recommended demo flow (5–7 minutes)

1. **Homepage / Hero:** Explain brand positioning — *Little minds. Big possibilities.* Modernized visual identity derived from the reference shield palette.
2. **Our learning approach:** Show the three value cards: curiosity, independence, connection. Emphasize this is positioning copy awaiting client alignment.
3. **Programs:** Show how families discover sample pathways instead of scrolling through dense texts.
4. **Learning Path Finder:** Select 4–6 years → Learning programs → Kindergarten result. Then show another path: 3–4 → School tour → visit CTA.
5. **School Life:** Filter gallery to Outdoor / Creative. Open a photo modal, emphasize that official Krishna media would later replace stock.
6. **Events:** Filter Upcoming concepts. Open an event, simulate RSVP. Explain how a live CMS could publish real announcements.
7. **Admissions:** Show the four-step journey and the tour form; submit sample information and show demo confirmation. Clarify no backend is connected.
8. **Trust & credentials:** Open About → show how real accreditation, teacher training, institutional documents could live once provided.
9. **Close:** Emphasize mobile-friendly experience, editable future direction, and deployment workflow via GitHub & Vercel.

## Client discussion questions after demo

- What is the school's preferred public-facing name (Perguruan Krishna, Krishna Montessori, or another officially approved name)?
- Which academic levels actually implement Montessori teaching? Which credentials can be substantiated?
- What photos/videos can be published, and who approves them?
- What are the confirmed programs, schedules, tour availability, location and contacts?
- Who will update events and galleries after launch (admin, marketing team, outside agency)?
- Where should new enquiries go (email, WhatsApp, admissions CRM)?
- Would the school prefer Indonesian, English, or bilingual pages?

## Sample next phase after approval

1. Align copy, official branding, program details, verified credentials, imagery.
2. Finalize CMS and lead capture requirements.
3. Production rebuild with backend integrations; test all flows, privacy notices, and mobile performance.
4. Publish on an approved domain with search indexing and tracking configured appropriately.

## Ground rules during pitch

**Never** describe the sample events, imagery, tuition, dates, campus photos, teacher qualifications, or programs as verified Krishna facts. Point to the explicit concept labels. The form interfaces and RSVP show client-side success states only.
